Factory Inventory Management System

A full-stack demo application: a Vue 3 single-page frontend talking to a Python FastAPI backend that serves in-memory mock data loaded from JSON files. No database — all filtering happens in memory.

Data Flow — End to End

1
User adjusts a filter

Period, warehouse, category, or status is changed in FilterBar.vue.

2
Shared state updates

The useFilters composable (singleton) updates its reactive refs — state persists across page navigation.

3
View requests data

The active view calls api.js, which builds query params from getCurrentFilters() and issues an Axios GET.

4
FastAPI receives the request

The matching route in main.py reads query parameters (warehouse, category, status, month).

5
In-memory filtering

apply_filters() matches warehouse/category/status; filter_by_month() resolves months and quarters (e.g. Q2-2025 → Apr–Jun).

6
Pydantic validation

Results are validated and serialized through Pydantic models, then returned as JSON.

7
Data sourced from memory

All records were loaded once at startup by mock_data.py from server/data/*.json.

8
View stores & derives

Raw response lands in refs; computed properties derive totals, statuses, and chart series.

9
Render

Tables, KPI cards, and custom SVG charts render — localized to EN or JA with the matching currency symbol.
